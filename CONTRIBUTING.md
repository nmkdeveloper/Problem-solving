# Contributing

Thank you for contributing to this collection of competitive programming solutions.

## Adding a Solution

- Place the solution under the directory for its online judge.
- Create a problem directory using the problem identifier.
- Name the source file after the problem identifier.
- Use standard C++17 unless the problem requires another version.
- Keep the solution self-contained and avoid committing generated binaries.
- Test the solution against the sample cases and relevant edge cases before submitting.

## Pull Requests

- Explain which problem is addressed and summarize the algorithm.
- Include the online judge and problem identifier.
- Confirm that the code compiles locally.
- Keep each pull request focused on related changes.
- Do not include copied solutions without permission or proper attribution.

Maintainers may request changes to improve correctness, clarity, or consistency.
