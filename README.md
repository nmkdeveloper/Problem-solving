# Problem Solving

A collection of competitive programming solutions written in C++.

## Repository Structure

Solutions are organized by online judge and problem identifier:

```text
1 - ONLINEJUDGE/
├── codeforces.com/
└── oj.cppro.vn/
```

Each problem directory contains its solution source file and follows the naming convention `<problem-id>.CPP`.

## Building and Running

A C++17-compatible compiler is recommended. For example, with GCC:

```bash
g++ -std=c++17 -O2 -Wall -Wextra -o solution path/to/solution.CPP
./solution
```

Provide input through standard input, as required by the problem statement.
